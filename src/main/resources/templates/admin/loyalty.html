Программа лояльности

Добавить порог

Как только сумма всех заказов клиента достигает указанного порога, ему автоматически начинает начисляться кешбэк в бонусах за каждый подтверждённый заказ. Один бонус равен одному рублю, а покупатель может списать бонусы при оформлении.

Порог (сумма заказов, ₽) Кешбэк Действия
5000 ₽ 5% Редактировать
Пороги ещё не заданы — бонусы по программе лояльности не начисляются.
